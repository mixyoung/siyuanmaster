## 实机发现并修复

首次安装后的覆盖会话打开返回 `coverage write readback mismatch`。落盘已经发生，错误来自将回读对象直接 `JSON.stringify` 与原字符串比较：宿主 JSON 解码可能重排对象键。

修复为递归忽略对象键顺序的 JSON 值比较，数组顺序、字段值和原始类型仍严格一致；同时用于覆盖账本和策略迁移写回验证。新增回归先在旧比较方式下失败，再在修复后通过。首次失败审计保留，未追溯改记成功。
